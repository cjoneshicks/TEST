# Fitness Tracker

A simple browser-based fitness tracker to help you hit **5 workouts per week**.

## Features

- Mark workouts complete by day (Monday-Sunday)
- Weekly progress bar toward a 5-session goal
- Quick "Mark today complete" action
- View the last 8 weeks of performance
- Data is saved in browser `localStorage`

## Run locally

1. Open `index.html` in your browser.
2. Mark completed workouts as you go.
3. Stay at or above **5 / week** to hit your goal.
